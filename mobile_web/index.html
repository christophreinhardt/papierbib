Hilfe

Auf dem iPhone zuerst „Kamera starten“ erlauben. Für ISBN und Barcode wird die Rückkamera verwendet. Das Plugin nutzt die größtmögliche vom Gerät gemeldete Kameraauflösung.

ISBNs werden lokal geprüft und mit lobid-resources / hbz abgefragt. Bei Buchrücken und Titelblättern kannst du das Foto speichern, OCR versuchen und die erkannten oder manuell ergänzten Angaben suchen.

Die Tabelle liegt lokal im Browser. JSON eignet sich als Projektzwischenstand; CSV kann später in die Papierbibliothek übernommen werden. Für GitHub Pages ist kein API-Schlüssel nötig.
